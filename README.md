### 🎓 Task 1 — Landing Page
An educational landing page for **The Paradigm Institute**, presenting its courses and approach to learning.

- Sticky navigation with section links.
- Hero section with clear calls to action.
- Six course cards, About and Why Learn With Us sections.
- Clearly marked placeholder contact details.
- Responsive layouts using CSS Grid and Flexbox.

### 👨‍💻 Task 2 — Personal Portfolio
A personal portfolio introducing my software engineering background, technical skills and projects.

- Profile section with an initials avatar.
- About Me, Skills, Projects and Contact sections.
- Project cards featuring AuralSight, iCampus360 and LandSnap.
- Smooth section navigation and responsive styling.
- Clearly identified placeholders for unavailable profile or repository links.

### 🌡️ Task 3 — Temperature Converter
An interactive tool for converting temperatures between **Celsius, Fahrenheit and Kelvin**.

- Results displayed in all three units.
- Validation for empty, invalid and non-finite input.
- Absolute-zero boundary checks.
- Convert, Enter-to-submit and Reset functionality.
- Accessible error messages and result announcements.

## 🛠️ Technology Stack

- **HTML5** — semantic page structure.
- **CSS3** — styling, responsive layouts and focus states.
- **Vanilla JavaScript** — conversion logic and input validation in Task 3.

No frameworks, backend services or build tools are required.

## ▶️ Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/i-am-gk/OIBSIP.git
   ```

2. Open the folder of the project you want to explore.
3. Double-click its `index.html` file to open it in your browser.

You can also download the repository using **Code → Download ZIP**, extract it and open any project's `index.html`.
