# The Paradigm Institute Landing Page

Author: Ghani Abdul Rehman Khan  
Internship Track: Oasis Infobyte Web Development & Designing  
Task: Level 1, Task 1 - Landing Page

## Objective

Create an original, polished educational landing page for The Paradigm Institute, an institute offering technology, academic and English language courses.

## Implemented Features

- Sticky navigation bar with working anchor links for Home, Courses, About and Contact.
- Hero section with the required headline, subheadline and two call-to-action links.
- Course cards for six institute programs.
- About section with concise introductory content.
- "Why Learn With Us?" section focused on practical projects, structured learning and confidence building.
- Contact section with clearly marked placeholder details only.
- Footer with placeholder social/contact links, developer credit and Oasis Infobyte task credit.
- Responsive layout using CSS Grid and Flexbox.
- Accessible focus styles, semantic HTML, viewport meta tag, smooth scrolling, reduced-motion support and scroll offset for sticky navigation.
- Local decorative SVG asset, with no external images or online font dependency.

## Technologies Used

- HTML5
- CSS3
- Local SVG asset

No JavaScript, frameworks, package installation, backend or build tools are used.

Manual browser checklist:

- Open `index.html` directly.
- Check widths near 375px, 768px and 1440px.
- Confirm Home, Courses, About and Contact navigation links scroll to the correct sections.
- Confirm Explore Courses and Get in Touch buttons scroll to Courses and Contact.
- Tab through links and confirm visible keyboard focus.
- Confirm the sticky header does not cover section headings after navigation.
- Confirm there is no horizontal scrolling or overlapping content on mobile.
